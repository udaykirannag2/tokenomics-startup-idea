# Tokenomics Startup Idea

A workspace for brainstorming startup ideas in AI tokenomics: reducing, measuring and governing what AI and agents cost.

## Contents

- [ideas/ai-tokenomics-startup-ideas.md](ideas/ai-tokenomics-startup-ideas.md): the consolidated idea list, market gaps, crowded spaces to avoid, a ranked shortlist and a suggested build order.

## Current direction

Start with an open-source **agent cost profiler** that shows the cost per successful outcome and where the waste is. Then add cost per merged PR for coding agents, FinOps cost-per-outcome reporting, and an AI commitment optimizer.
