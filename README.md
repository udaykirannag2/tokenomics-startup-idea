# Tokenomics Startup Idea

A workspace for finding a startup idea in AI tokenomics: reducing, measuring and governing what AI and agents cost, and proving the value they create.

**Approach:** problem first. Document the challenges, validate them with interviews, then choose an idea. Nothing is locked yet.

## Contents

| Folder | What's inside |
|---|---|
| [challenges/](challenges/ai-tokenomics-challenges.md) | Catalog of AI cost and value challenges by category, with evidence, stakeholders, current solutions, gaps and an opportunity score |
| [interviews/](interviews/interview-guide.md) | Interview guide and a log template for validating challenges |
| [market/](market/competitive-landscape.md) | Competitive landscape: 20 companies across 5 layers, capability matrix, USPs, threat ratings and a tracking log |
| [ideas/](ideas/ai-tokenomics-startup-ideas.md) | 22 candidate ideas, crowded spaces to avoid, and a provisional shortlist |

## Workflow

1. Add or refine challenges in `challenges/`.
2. Run interviews and log each one in `interviews/`.
3. Mark challenges as validated and re-score the opportunities.
4. Check candidate ideas against `market/competitive-landscape.md` and log new competitor moves there.
5. Map the validated challenges to ideas and pick one to test.
